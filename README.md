# Le Petit Horticulteur

Site vitrine de la pépinière « Le Petit Horticulteur » (Labergement-lès-Seurre, Bourgogne) :
- Accueil, catalogue des plantes, conseils hebdomadaires (parution le mercredi), contact (téléphone, email, carte et itinéraire).

Le site est servi par une application Mistral Apps (FastAPI + fichiers statiques dans `apps/api/src/api/static`).
